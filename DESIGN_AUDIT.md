# Аудит дизайна — proxy.pqnet.ru

## Общие замечания
- Смешение стилей: index.html использует собственные CSS-классы, а index.php/dashboard/admin используют Bootstrap 5.3 + кастомные классы. Нет единой дизайн-системы.
- Тёмной темы нет; жёстко заданы светлые цвета.
- Инлайн-стили (`style="..."`) разбросаны по разметке, дублируют CSS.

## Конкретные проблемы

### index.html
- Форма «Связаться со мной» отправляется на несуществующий `/send.php` — битая ссылка.
- Нет состояний focus/hover для input/textarea кроме button.
- Контраст кнопки #1a56db на белом фоне ок, но нет focus-ring для a11y.
- Нет адаптивности для мобильных (max-width 720px ок, но padding фиксирован).

### index.php (логин)
- Карточка 400px, но на очень узких экранах padding 2.5rem может быть тесным.
- Нет показа/скрытия пароля.
- Нет ссылки «Забыли пароль?».
- Ошибка выводится только через ?error=1, нет поля для сообщения.

### dashboard.php
- Много inline-стилей; карточки `.card-light` дублируют Bootstrap.
- Таблица приложений не адаптивна (нет `.table-responsive`).
- QR-модалка создаёт QR при загрузке даже если модалка закрыта — ок, но размер 160px маловат.
- Поля копирования используют `alert()` — плохой UX; лучше toast.
- Нет empty-state для списка приложений.
- Иконки приложений fallback «APP» выглядят как заглушка.

### admin.php
- Таблица пользователей без горизонтального скролла на мобильных.
- Модалки с id на md5(email) — коллизии возможны.
- Нет подтверждения удаления приложения.
- Статусные сообщения `$msg` выводятся? Проверить — в коде не видно вывода $msg в шаблоне.

### header_status.php
- Метрики захардкожены (CPU 18.4%, RAM 1.68/4 GB) — не реальные данные.
- Иконка ключа — огромный SVG-path (128x128) встроен inline, раздувает HTML.
- `bg-indigo-50`, `text-indigo-600` и т.п. — Tailwind-классы, но Tailwind не подключён → стили не применяются.
- Классы `w-100` у метрики CPU/RAM без контейнера нормальной ширины — визуально неровно.

## Рекомендации (приоритет)
1. Подключить Tailwind или убрать tailwind-классы; сейчас они no-op.
2. Вынести общие стили в один CSS-файл, убрать inline.
3. Добавить focus-visible стили и aria-атрибуты.
4. Заменить alert() на toast-уведомления.
5. Сделать таблицы responsive.
6. Реализовать реальные метрики или убрать блок.
7. Добавить empty-states и подтверждения деструктивных действий.
8. Единая цветовая палитра и тёмная тема (опционально).
