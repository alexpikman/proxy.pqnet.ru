НОВОЕ ПОДКЛЮЧЕНИЕ

Добавить сервер 3x-ui

Удалённые панели должны использовать HTTPS. API Token шифруется на сервере и никогда не возвращается в браузер. При редактировании пустое поле токена сохраняет прежний ключ.

Правила эксплуатации

  • Секреты 3x-ui и ключи API хранятся вне публичной директории.
  • Административные операции проверяют роль на сервере.
  • Начисления и списания монет фиксируются в журнале.
  • Резервные копии хранятся вне web root и не публикуются.
